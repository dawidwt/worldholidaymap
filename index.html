        Data: date-holidays. Population: World Bank + REST Countries fallback. Reference: Timeanddate - Holidays Worldwide

        The map uses the generated 2026 public-holiday dataset in this project. Holidays are calculated with the date-holidays library and filtered to entries marked as public. Timeanddate - Holidays Worldwide is linked as a reference for manual comparison, not scraped live by the app.

        Population totals are approximate. For each selected date, the app sums country-level World Bank SP.POP.TOTL population estimates for highlighted countries and uses REST Countries population values only for map areas missing from the World Bank snapshot. It does not account for regional holidays, partial observance, subnational populations, or people working despite a public holiday.

        Rankings can be sorted by either the number of countries with a public holiday or by the summed population estimate for those countries. Countries and territories without holiday coverage are omitted from the relevant totals.
